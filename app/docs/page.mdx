# Make your first request

Three steps and about three minutes. You'll stream a response from **Synapse Flash**, our fastest general model. Pick your language in any code block; the rest of the docs will follow.

## Get an API key

Sign up with email or GitHub. Your first key is created for you and shown once, so copy it somewhere safe. Free accounts get $5 of credit every month, no card needed.
